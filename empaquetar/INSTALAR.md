# Cómo se instala eterOS desde este archivo

> Esto lo lee Claude Code, no la persona. La persona solo pegó una línea como *"Instalá eterOS desde
> el archivo que bajé"*.

1. **Copiá cada carpeta de `skills/` a `~/.claude/skills/`**, con el mismo nombre. Si alguna ya existe,
   es una actualización: seguí la sección *"Si lo que te piden es actualizar"* de
   `skills/eteros/SKILL.md` en vez de este paso.
2. **No toques `~/.claude/eteros/` ni `~/.claude/autoconocimiento/`** si existen: ahí está el sistema
   de la persona. Este archivo trae el método, no su negocio.
3. **Arrancá el skill `eteros`** como si la persona hubiera dicho *"armá el eterOS de mi negocio"*.
   Si junto con la línea pegó un bloque que empieza con `=== AUDITORÍA PARA ETEROS ===`, pasáselo: el
   skill sabe qué hacer con él.
4. **Si te pidió solo el tramo de encontrar su diferencial**, copiá únicamente
   `skills/autoconocimiento/` y arrancá ese.

`NOVEDADES.md`, al lado de este archivo, es lo que se le cuenta a la persona cuando actualiza.
